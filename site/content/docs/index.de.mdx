---
title: Shepherd
description: Eine native macOS-Review-Inbox, die Pull Requests aus allen Repositorys an einem Ort bündelt.
---

Shepherd ist eine macOS-App zum Reviewen von GitHub Pull Requests. Sie holt jeden Pull Request, der dich braucht, aus jedem Repository in eine lokale, tastaturgesteuerte Inbox. Du sortierst, reviewst und mergst, ohne einen Browser-Tab zu öffnen.

## Für wen ist Shepherd

Coding-Agents öffnen Pull Requests schneller, als du sie lesen kannst. Shepherd ist für alle, die diese Flut reviewen müssen: viele Repositorys, viele kleine Pull Requests, manche von Menschen und manche von Agents wie Claude Code oder Copilot.

Jede Zeile zeigt CI-Status, Review-Status und Diff-Größe. Shepherd arbeitet mit einer lokalen Datenbank, deshalb öffnet die Inbox schnell und bleibt auch offline nutzbar. Reviews und Merges, die du einreihst, werden gesendet, sobald GitHub erreichbar ist.

## Schnellstart

1. **Installieren.** Lade die App herunter oder nutze Homebrew. Siehe [Installation](/de/docs/installation).
2. **Anmelden.** Bestätige einen kurzen Code auf github.com oder füge ein Personal Access Token ein. Siehe [GitHub-Token](/de/docs/github-token).
3. **Repositorys beobachten.** Drücke `⇧⌘A` und gib für jedes Repository, für das du verantwortlich bist, `owner/repo` ein. Pull Requests, in die du involviert bist, findet Shepherd ohnehin.
4. **Inbox öffnen.** Starte mit **Braucht mein Review**. Mit `⌘R` synchronisierst du sofort. Siehe [Inbox](/de/docs/inbox).
5. **Reviewen und mergen.** Öffne einen Pull Request, lies den Diff und genehmige, kommentiere oder merge. Siehe [Review](/de/docs/review) und [Merge](/de/docs/merging).

<Callout type="info">
Shepherd spricht nur mit github.com. GitHub Enterprise Server wird nicht unterstützt.
</Callout>
